# f18.bin - dau tach tu chu Viet

Luoi 18 hang (0 = tren cung). Than chu: chu thuong x-height = hang 9-14, chu hoa (cap) = hang 5-14, duoi = hang 15-17. Dau = bitmap f18 tru bitmap chu goc (i dung than khong cham). `gap` = so hang trong giua day dau va dinh than (0 = sat). `dx` = lech tam dau so voi tam bbox than, don vi pixel (+ = phai).
