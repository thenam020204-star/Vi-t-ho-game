# Bộ tool đã dùng
- fonts/, fontgen/, java/ (BitmapFont), pixeltext-kit/, check_all.sh, env.sh: từ Tool_Viet_Hoa_NAM_P.zip (người dùng gửi, có trong repo gốc).
- freej2me_plus.jar: FreeJ2ME-Plus, kèm trong zip tool. Tham số dòng lệnh: `jar <0|1> width height scale`.
- cfr.jar: CFR 0.152 (https://github.com/leibnitz27/cfr/releases).
- proguard.jar: ProGuard 7.4.2 (https://github.com/Guardsquare/proguard/releases/tag/v7.4.2).
- lib/ecj.jar: Eclipse ECJ 3.26.0 (Maven Central org.eclipse.jdt:ecj:3.26.0).
- lib/asm-9.8.jar, lib/asm-tree-9.7.1.jar, lib/asm-commons-9.7.1.jar: OW2 ASM (Maven Central org.ow2.asm).
- JDK dùng để build: OpenJDK 21. Python 3.13 + Pillow 12.3, numpy 2.5, opencv-python-headless 5.0 (chỉ cho make_map.py).
- Đã bỏ khỏi gói: pg.tgz, proguard-7.4.2/ (chỉ cần proguard.jar), _src/ (cây gốc của zip tool).
